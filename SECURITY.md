# Security Policy

## Scope

This repository is editor configuration: one settings file, an extension list and guides. It
contains no service and no library. In scope:

- An extension id in `extensions.txt` that points at a different or malicious extension
- A setting that weakens security, for example granting extensions wider capabilities than Zed's
  defaults
- A setup instruction that would leave insecure file permissions behind

## Out of scope

- A vulnerability in Zed itself or in a listed extension, report that upstream

## Reporting a vulnerability

> [!IMPORTANT]
> Report privately, not in a public issue. Email contact@isaacadjei.me with details and
> reproduction steps. Expect an acknowledgement within a few days.
